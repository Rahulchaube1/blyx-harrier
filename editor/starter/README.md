# Harrier starter

Apply time and assurance policy to a session after upstream identity verification.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Harrier** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
1
1
8
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/harrier) · [View the release](https://github.com/Rahulchaube1/blyx-harrier/releases/tag/v0.1.0)
